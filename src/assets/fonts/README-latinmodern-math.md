# Latin Modern Math

`latinmodern-math.woff2` is Latin Modern Math (GUST e-foundry), the OpenType
maths font of LaTeX's default typeface. It gives the app's MathML formulas the
same look on every device, independent of installed fonts.

- Source: `https://mirrors.ctan.org/fonts/lm-math/opentype/latinmodern-math.otf`
  (SHA-256 `6075562b771f8b82f0c179e363389684f2dd09de30038269e2628e504bd7be0f`),
  downloaded 2026-10-10.
- Converted to WOFF2 unchanged (format only) with
  `fonttools ttLib.woff2 compress` (fonttools 4.55.3).
