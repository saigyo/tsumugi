# User-facing Seed Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let the user fix the sampling seed, rerun a cut-off real-model run with a higher token limit, and share a run as a link that fills in the prompt bar.

**Architecture:** The worker already seeds each cycle's draw from `run-start.seed`; a new `RunOptions.seed` lets the app choose it. A pure `shareLink` module builds and parses the link (settings in the URL hash). The prompt bar gains a seed field and initial values from a link; the run-end detail gains the seed text and two buttons, wired through a small zustand request store like `knockoutRequest`.

**Tech Stack:** React 19, TypeScript, zustand, vitest + Testing Library, transformers.js worker.

**Spec:** `docs/superpowers/specs/2026-11-02-user-seed-design.md`

## Global Constraints

- Real-model only: no seed field, no buttons and no seed text for simulated runs.
- Seed range: integers 0 to 4294967295. Empty field = random seed per run.
- Continue limit: N = min(100, 2 × maxNewTokens); button label `Run again with N tokens`.
- Link format: `location.origin + location.pathname` + `#run=1&p=…&f=chat|text&s=…&t=…&k=…&n=…&seed=…&rev=…`; `s` only for chat, `rev` absent for the stock model; values URL-encoded.
- Copy: `Link copied`; mismatch note `This link was made with model version vX; the loaded model is vY, so the text may differ.`; disabled-continue title `Load model version vX to continue this run`; glossary tip `Same seed, prompt and settings give the same text.`
- Revisions compare as strings; "absent" (run without `revision`, link without `rev`, engine `revision === null`) means the stock model and is shown as `stock` in the copy above.
- Commit trailer: `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

- A prompt with `&`, `#`, `=`, newlines or non-Latin text (e.g. `紬 & co #1`) must round-trip through the link unchanged — Task 1 test `round-trips awkward prompts`.
- A hand-edited link with out-of-range or junk values (`t=9`, `k=0`, `n=abc`, `seed=-1`) fills the valid fields and leaves the rest at defaults — Task 1 test `bad values fall back`.
- Continue on a run whose prompt was truncated must not be offered — Task 4 test `no continue for a truncated prompt`.
- Continue must use the run's seed even when the prompt bar has a different seed typed — Task 5 test via `continueRun` handler (App passes `start.seed`).
- Clearing the seed field must return to random seeds, not keep the old number — Task 3 test `clearing the seed sends no seed`.

### Task 1: Share link module

**Files:**
- Create: `src/app/shareLink.ts`
- Test: `src/app/shareLink.test.ts`

**Interfaces:**
- Produces:
  - `interface ShareSettings { prompt: string; format: PromptFormat; params: GenParams; seed: number; rev?: string }`
  - `buildShareLink(base: string, s: ShareSettings): string` — `base` is `location.origin + location.pathname`.
  - `parseShareLink(hash: string): SharedRun | null`, where `SharedRun = { prompt?: string; format?: PromptFormat; params?: Partial<GenParams>; seed?: number; rev?: string }` — `null` when the hash has no `run=1`; otherwise only the fields that parsed and are in range (temperature 0–2, top-k 1–10, max tokens 1–100 integer, seed 0–4294967295 integer).
  - `shareableRun(events: TraceEvent[]): ShareSettings | null` — settings from the `run-start` when the run is real, has a `seed`, has no `knockout` and its `run-end` reason is `eos` or `max-tokens`; otherwise `null`. Used by the run-end detail and the shelf.
  - `continueLimit(maxNewTokens: number): number | null` — `min(100, 2 × n)`, `null` when `n >= 100`.
  - `parseSeed(raw: string): number | null | undefined` — `null` for empty/whitespace (random), the integer when valid, `undefined` when invalid (caller keeps the previous value).

- [ ] **Step 1: Write the failing tests** — `round-trips text and chat settings` (chat with a custom system prompt keeps `format.system`; text has no `s` key in the output), `round-trips awkward prompts` (`'紬 & co #1\n= x'`), `omits rev for the stock model`, `returns null without run=1` (`''`, `'#foo'`), `bad values fall back` (`#run=1&p=hi&t=9&k=0&n=abc&seed=-1` → `{ prompt: 'hi' }` plus no params/seed keys), `continueLimit` (`20→40`, `60→100`, `100→null`), `shareableRun` (settings for a real seeded run ended by `eos` or `max-tokens`; `null` for sim, no seed, knockout, `aborted`, `error`, and a run without `run-end`), `parseSeed` (`''→null`, `' 42 '→42`, `'4294967295'→4294967295`, `'4294967296'`, `'-1'`, `'1.5'`, `'x'` → `undefined`).
